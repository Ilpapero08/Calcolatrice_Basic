## 🦆 Il Papero

**Il Papero** sono io, quindi ho fatto una calcolatrice web minimalista con un'interfaccia intuitiva.

L'obiettivo è semplice:

> **Semplice, precisa, sempre pronta.**

Niente menu complicati, niente funzioni inutili: solo una calcolatrice pronta a fare il suo lavoro.

---

## 🚀 Funzionalità

- ➕ Addizione
- ➖ Sottrazione
- ✖️ Moltiplicazione
- ➗ Divisione
- `%` Percentuale
- `±` Cambio del segno
- `AC` Reset completo
- `⌫` Cancella l'ultima cifra
- `,` Numeri decimali
- ⌨️ Supporto alla tastiera
- 📱 Interfaccia responsive
- 🎨 Design moderno e minimale

---

## 🎨 Design

L'interfaccia utilizza una palette chiara con:

- 🩵 tonalità azzurro chiaro
- 🟨 pulsanti dorati per le operazioni
- ⬜ sfondo pulito
- 🔵 tipografia scura e leggibile
- ✨ angoli arrotondati e ombre leggere

Il risultato è una UI semplice ma riconoscibile.

---

## ⌨️ Comandi da tastiera

Puoi utilizzare direttamente la tastiera per eseguire le operazioni.

| Tasto | Funzione |
|---|---|
| `0-9` | Inserisci numero |
| `+` | Addizione |
| `-` | Sottrazione |
| `*` | Moltiplicazione |
| `/` | Divisione |
| `Enter` | Calcola |
| `Backspace` | Cancella |
| `Escape` | Azzera |
| `,` / `.` | Decimale |
